# Установка Rembly OS одной командой

Для A73 / `K37MV1_BSP` добавлен отдельный установщик. Старые `tools/flash-rembly.sh` и `tools/restore-android.sh` не изменяются.

После `git pull` запускается одна команда:

```bash
bash rembly-install.sh
```

Установщик открывает цветную консоль Rembly OS и дальше работает сам:

1. Проверяет `adb`, `fastboot`, Python и базовые инструменты. На Arch/Ubuntu недостающие пакеты пытается поставить автоматически.
2. Проверяет или собирает актуальные `A73-linux-test.img` и `rembly-rootfs.img`. На Arch rootfs автоматически собирается в привилегированном Ubuntu-контейнере Podman, Distrobox вручную не нужен.
3. Ищет подключённый A73 по USB. Если планшет доступен по ADB, сам переводит его в Fastboot. Если он уже в Fastboot, продолжает сразу.
4. Проверяет `product = K37MV1_BSP` и `unlocked = yes`. Чужое или заблокированное устройство отклоняется до записи.
5. Временно запускает stage-1 через `fastboot boot`. До этого внутренняя память не меняется.
6. Уже внутри stage-1 определяет `boot`, `recovery` и `userdata` по настоящей GPT и их `PARTNAME`.
7. Делает резервную копию текущих `boot` и `recovery` и сохраняет рядом проверенные stock-образы.
8. Передаёт rootfs по ADB прямо в настоящий `userdata`. Это обходит известный баг старого LK A73, который неверно сообщает размер `userdata` и может зависнуть на большой записи через Fastboot.
9. Проверяет ext4 magic и метку `REMBLY`. Только после успешной проверки rootfs записывает `boot`.
10. Считывает boot обратно и сверяет SHA-256, затем перезагружает планшет.
11. На первом запуске Rembly OS сама запускает `rembly-autosetup`: железо, реальная RAM, экран, тач, драйверы, сеть и оптимизация.

## Защита

Полная установка стирает содержимое `userdata`. Установщик записывает только `userdata` и `boot`. Он не пишет `preloader`, `lk`, `gpt`, `nvram`, `nvdata`, `protect1/2`, `secro`, `system` или `vendor`.

Если временная stage-1 среда не подняла ADB, установка останавливается до первой записи. Если запись `userdata` или её проверка не удалась, постоянный `boot` ещё не меняется.

Резервные копии создаются в:

```text
backups/YYYYMMDD-HHMMSS/
```

Путь к последней копии также записывается в:

```text
out/last-backup-dir.txt
```

## Дополнительные режимы

Полная пересборка перед установкой:

```bash
bash rembly-install.sh --rebuild
```

Использовать уже существующие образы даже после смены Git commit:

```bash
bash rembly-install.sh --reuse-images
```
