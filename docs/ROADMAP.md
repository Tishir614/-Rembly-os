# Что ещё НЕ сделано (честный список)

* Wi-Fi / Bluetooth / SIM: код есть, но нужны файлы из вашего Android (`tools/extract_android_blobs.py`) и проверка на железе.
* Звук: ALSA-карта MediaTek может не появиться без Android-библиотек; регуляторы громкости готовы.
* Камера, GPS, датчики (акселерометр для авто-поворота), NFC: не поддерживаются (нужны драйверные оболочки Android).
* Аппаратное ускорение графики (Mali) не используется — только fbdev; видео 1080p будет тормозить.
* Установка на внутреннюю память (userdata): сознательно не сделана на первом этапе; образ грузится через `fastboot boot`.
* Suspend-to-RAM: не реализован (экран гасится, CPU уходит в idle ядром).
* Всё, что относится к запуску на реальном планшете, не проверено — присылайте `rembley-report`.
