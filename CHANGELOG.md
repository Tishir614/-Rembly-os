# Changelog

## 0.29
- **ИИ в Rembly Code** (`rembly_ai.py`, `rembly_aiui.py`): ключ или локальный сервер на выбор. Поставщики: Claude (Anthropic API), OpenAI-совместимые (OpenAI, OpenRouter, Groq, Gemini…), локальные (Ollama на ПК, llama.cpp-сервер, LM Studio и т. п.), свой адрес. Настройки в одном окне с кнопками «Проверить связь» и «Список моделей»; ключ хранится в `~/.config/rembly/ai.json` (права 600). Чат со стримингом справа (в портретной ориентации — снизу) с контекстом «файл / выделенное / список файлов проекта», кнопками «Вставить / Заменить выделенное / В новый файл / Копировать / Запустить в терминале», быстрыми действиями (объяснить, исправить, тесты, оптимизировать, ошибка из терминала); **Ctrl+K** — правка выделенного с просмотром разницы и применением одним шагом отмены; ответы с `<file path="…">` применяются через окно просмотра с резервными копиями в `.rembly-ai-backup`
- **ИИ сам создаёт проекты** («Новый проект ИИ»): вы описываете задачу и стек → ИИ составляет план (файлы, команды установки и запуска) → вы проверяете и снимаете лишнее → ИИ пишет файл за файлом (каждый со своим запросом, с прогрессом и кнопкой «Остановить») в НОВУЮ папку → git init, открытие проекта; команды ИИ выполняются только если вы их отметили и только в терминале на ваших глазах. Защиты: пути только внутри проекта, секретные файлы (`.env`, ключи) не создаются и не читаются, не более 60 файлов и 1 МБ, чёрный список опасных команд
- `rembly-ai` (разбор ошибок для `rembly-doctor`) использует тот же ключ/сервер, умеет Anthropic API; секреты в тексте ошибки маскируются
- **Серверы** (`rembly-ssh`): сохранённые подключения SSH / последовательный порт (picocom) / RDP (xfreerdp) / VNC / Telnet, быстрое подключение `user@host:порт`, вкладки-терминалы (Vte), панель клавиш для касания (Esc, Tab, залипающие Ctrl и Alt, стрелки, `| ~ / -`, копировать/вставить), авто-переподключение, ключи SSH (создать, скопировать, отправить на сервер), папки серверов как настоящие папки (sshfs) с открытием в Rembly Code и Файлах. Пароли нигде не сохраняются
- Терминал Rembly Code и «Серверы» используют общий модуль `rembly_term.py` (панель клавиш есть и в редакторе)
- Пакеты: `sshfs picocom freerdp2-x11 xtightvncviewer telnet`; плитка «Серверы» на рабочем столе вместо «Блокнота» (он остался в «все приложения»)

## 0.28
- **Rembly Player** (`rembly-player`): музыка, видео и фото в одном приложении под сенсор. Музыка: библиотека с тегами и обложками (mutagen, кэш), очередь, вперемешку/повтор, полоса перемотки в виде настоящей волны трека, строка «HUD» с данными mpv (кодек, частота, битрейт), управление через MPRIS (`playerctl`, медиа-карточка рабочего стола). Видео: mpv встроен в окно (вывод x11, без GPU, программное декодирование, поздние кадры отбрасываются), касание — панель, двойное касание слева/справа — −10/+10 с, продолжение с места остановки, скорость, субтитры, дорожки, полный экран, предупреждение, если планшет не успевает. Фото: сетка эскизов (кэш на диске, только видимое), просмотр со свайпом, щипком, двойным касанием, поворотом и слайдшоу. Библиотека: `rembly_media.py`
- **Rembly Code** (`rembly-code`): лёгкий редактор в духе VS Code на GTK + GtkSourceView + VTE (без Electron): проводник, вкладки, подсветка (чёрно-белая и «матричная» схемы), поиск/замена, палитра команд Ctrl+P, встроенный терминал, запуск по F5, ветка git, проверка синтаксиса Python при сохранении, большие файлы без подсветки, восстановление сессии. Настоящий VS Code — по желанию: `rembly-install-vscode` (скачивает официальный пакет ARM, проверяет SHA-256, ставит с «лёгкими» настройками); **на этом планшете не проверен**
- **Стиль «Хакер»** (`rembly-style mono|hacker`, Настройки → Экран и питание → Стиль оформления): зелёный люминофор на чёрном во всех приложениях Rembly, значках, рамках окон (тема xfwm4 «Rembly-Hacker», `tools/gen_wmtheme.py --hacker`), GTK-приложениях, терминале, уведомлениях; приглашение `┌──(root@rembly)-[~]` и баннер в терминале; строка `$ neofetch█` с мигающим курсором на рабочем столе; цифровой дождь на экране блокировки и приложение «Матрица» (`rembly-matrix`, один глиф на столбец за кадр, ≈8 кадров/с, пауза при нагрузке)
- Пакеты: добавлены `gir1.2-gtksource-4`, `gir1.2-vte-2.91`, `python3-mutagen`; убраны `audacious` и `gpicview` (их заменил плеер, образ легче)

## 0.8 — самолечение Wi-Fi и диагностика
* `rembly_heal`: после неудачного запуска `wmt_*` разбирает `strace`, ошибки загрузчика Android и `dmesg`, чинит пути/библиотеки/прошивки/каталоги (в т.ч. достаёт файлы из раздела Android), до 4 попыток; `rembly-net debug`
* `rembly-selftest` (проверка системы), журнал сбоев и уведомления для всех программ, `rembly-report --usb`, `strace` в образе, `docs/TROUBLESHOOTING.md`

## 0.7 — драйверы ставятся сами
* `rembly-drivers`: достаёт файлы Wi-Fi/BT/GPS/modem из разделов Android `system`/`vendor` на самом планшете (read-only), ставит их и запускает Wi-Fi; безопасная распаковка
* Автозапуск при первой загрузке, перед установкой во внутреннюю память и по кнопке (Настройки → Сеть, окно Wi-Fi); страна Wi-Fi; regdb/crda/iw из Ubuntu при наличии сети
* `ANDROID_DUMP=<папка> sudo -E rootfs/build-rootfs.sh` вшивает файлы в образ; скрипт прошивки показывает, включены ли они

## 0.6 — установка и свои добавки

* `rembly-install-internal` + страница «Установка на планшет»: копирует работающую систему во внутренний userdata одним нажатием, с прогрессом; автоматическое расширение ФС при первом запуске

## 0.5 — Linux-программы, скорость, «живой» стол
* Совместимость: `rembly-pkg` (проверка места), `rembly-install` (.deb/AppImage), `rembly-nosandbox`, `rembly-compat`, ассоциации файлов, окружение для Qt/Java/GL
* Приложения запускаются с пониженным приоритетом, интерфейс — с повышенным (Xorg/xfwm4/оболочка)
* Запуск оболочки ~3,6 раза быстрее: кэш иконок на диске, обои и размытие без PIL
* «Живой» стол: звёзды, падающая звезда, плавное появление, прыжок в доке, приветствие, погодная иконка; адаптивно и с паузой, когда стол закрыт окнами

* Проверка сенсора (мишени + след), выбор стиля иконок, команды интерфейса через /run/rembly/ctl
