## 0.8 — самолечение Wi-Fi и диагностика
* `rembly_heal`: после неудачного запуска `wmt_*` разбирает `strace`, ошибки загрузчика Android и `dmesg`, чинит пути/библиотеки/прошивки/каталоги (в т.ч. достаёт файлы из раздела Android), до 4 попыток; `rembly-net debug`
* `rembly-selftest` (проверка системы), журнал сбоев и уведомления для всех программ, `rembly-report --usb`, `strace` в образе, `docs/TROUBLESHOOTING.md`

## 0.7 — драйверы ставятся сами
* `rembly-drivers`: достаёт файлы Wi-Fi/BT/GPS/modem из разделов Android `system`/`vendor` на самом планшете (read-only), ставит их и запускает Wi-Fi; безопасная распаковка
* Автозапуск при первой загрузке, перед установкой во внутреннюю память и по кнопке (Настройки → Сеть, окно Wi-Fi); страна Wi-Fi; regdb/crda/iw из Ubuntu при наличии сети
* `ANDROID_DUMP=<папка> sudo -E rootfs/build-rootfs.sh` вшивает файлы в образ; скрипт прошивки показывает, включены ли они

## 0.6 — установка и свои добавки
* `tools/flash-rembly.sh` (test / install-recovery / install-boot): проверки устройства, образов и бэкапа, список разрешённых разделов (boot, recovery, userdata), `--dry-run`; `tools/restore-android.sh`
* `rembly-install-internal` + страница «Установка на планшет»: копирует работающую систему во внутренний userdata одним нажатием, с прогрессом; автоматическое расширение ФС при первом запуске
* sparse-образ rootfs для быстрой прошивки; `docs/INSTALL.md`
* Свои добавки: приложение «Таймер» (таймер/секундомер/будильник), «Освободить место» (`rembly-clean`)

## 0.5 — Linux-программы, скорость, «живой» стол
* Совместимость: `rembly-pkg` (проверка места), `rembly-install` (.deb/AppImage), `rembly-nosandbox`, `rembly-compat`, ассоциации файлов, окружение для Qt/Java/GL
* Приложения запускаются с пониженным приоритетом, интерфейс — с повышенным (Xorg/xfwm4/оболочка)
* Запуск оболочки ~3,6 раза быстрее: кэш иконок на диске, обои и размытие без PIL
* «Живой» стол: звёзды, падающая звезда, плавное появление, прыжок в доке, приветствие, погодная иконка; адаптивно и с паузой, когда стол закрыт окнами

## 0.4 — сенсорное управление, логотип, иконки, плавность
* Жесты: долгое нажатие = правый клик, свайпы от краёв (быстрые настройки / приложения / окна), кнопка экранной клавиатуры на краю
* Проверка сенсора (мишени + след), выбор стиля иконок, команды интерфейса через /run/rembly/ctl
* Логотип и аватар из вашего изображения: заставка загрузки, экран блокировки, «О планшете», аватар
* Современные иконки-плитки; опросы системы без подпроцессов (простой оболочки 1,66 % → 0,20 %), автоэкономия ≤ 20 %
