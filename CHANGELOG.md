# Changelog

## 0.4 — сенсорное управление, логотип, иконки, плавность
* Жесты: долгое нажатие = правый клик, свайпы от краёв (быстрые настройки / приложения / окна), кнопка экранной клавиатуры на краю
* Проверка сенсора (мишени + след), выбор стиля иконок, команды интерфейса через /run/rembley/ctl
* Логотип и аватар из вашего изображения: заставка загрузки, экран блокировки, «О планшете», аватар
* Современные иконки-плитки; опросы системы без подпроцессов (простой оболочки 1,66 % → 0,20 %), автоэкономия ≤ 20 %

## 0.3 — Wi-Fi пальцем
* Экранная клавиатура Onboard (автопоказ, прижата к низу), одна сессия D-Bus, автоматическое разворачивание окон, сенсорное окно Wi-Fi

## 0.2 — большое обновление
* Rembley Shell: быстрые настройки, переключатель окон, сигналы управления (кнопка питания), мастер первого запуска
* Новые программы: rembley-settings, rembley-store, rembley-lock (PIN), rembley-power (экран/кнопка/батарея/часы), rembley-report, rembley-update, rembley-eco
* Уведомления (dunst), звук (ALSA-регуляторы), русская раскладка + Alt+Shift, часовые пояса, сохранение времени без RTC, NTP
* Загрузочная заставка в stage 1, общая библиотека rembleyui, настройка DPI
* Документация: USER-GUIDE, ROADMAP, NETWORK

## 0.1
* Stage 1 initramfs (adb, /dev без devtmpfs, поиск rootfs), Ubuntu 20.04 armhf rootfs, Rembley desktop, сеть (код), zram/earlyoom
